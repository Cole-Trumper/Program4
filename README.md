# CS1121 Program 4. A Coney Conundrum

Produce a menu of all possible combinations of their ingredients and price for hotdogs from a hotdog stand. It was needed to show all 128 possible combinations of the toppings on the hotdogs.

## Requirements

-Requirement 1: HotDog.java file downloaded
-Requirement 2: Git for accessing the file

## Usage
Run the program with the following command:
java Hotdog.java
